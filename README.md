# Retro Barbershop Bot 🤖

Telegram бот для записи в барбершоп с системой управления записями и админ-панелью.

## Возможности

### Для клиентов:
- 📅 Запись на стрижку через удобный интерфейс
- 👨‍💼 Выбор мастера с рейтингом
- 💇 Выбор нескольких услуг сразу
- 📅 Выбор даты (на 2 недели вперед)
- 🕐 Выбор времени с проверкой занятости
- 📱 Ввод контактных данных
- 📋 Просмотр списка мастеров и услуг
- 📍 Контактная информация

### Для администратора:
- 🔐 Доступ по PIN-коду (по умолчанию: `1234`)
- 📋 Просмотр всех записей
- ➕ Добавление новых услуг
- ➕ Добавление новых мастеров
- 🗑 Удаление услуг
- 🗑 Удаление мастеров
- 📊 Статистика записей

## Установка

### 1. Клонирование и установка зависимостей
```bash
cd retro-barbershop-bot
npm install
```

### 2. Получение токена бота
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Следуйте инструкциям и получите токен

### 3. Настройка
Создайте файл `.env` в корне проекта:
```
BOT_TOKEN=ваш_токен_здесь
```

Или отредактируйте файл `src/bot.js` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен.

### 4. Запуск
```bash
# Обычный запуск
npm start

# Запуск с автоперезагрузкой (для разработки)
npm run dev
```

## Использование

### Для клиентов:
1. Найдите бота в Telegram по username
2. Нажмите `/start`
3. Используйте кнопки меню:
   - **📅 Записаться** - начать процесс записи
   - **👨‍💼 Наши мастера** - список барберов
   - **💇 Услуги и цены** - прайс-лист
   - **📍 Контакты** - адрес и телефон

### Процесс записи:
1. Выберите услуги (можно несколько)
2. Выберите мастера
3. Выберите дату
4. Выберите свободное время
5. Введите имя и телефон
6. Подтвердите запись

### Для администратора:
1. Нажмите **⚙️ Админ панель**
2. Введите PIN-код: `1234`
3. Используйте админское меню:
   - **📋 Все записи** - просмотр бронирований
   - **➕ Добавить услугу/мастера**
   - **🗑 Удалить услугу/мастера**
   - **🚪 Выйти из админки**

## Хранение данных

Все данные хранятся в файле `data/database.json`:
- Список услуг
- Список мастеров
- Записи клиентов
- Сессии администраторов

## Кастомизация

### Изменение PIN-кода
Отредактируйте `ADMIN_PIN` в файле `src/bot.js`:
```javascript
const ADMIN_PIN = 'ваш_новый_pin';
```

### Изменение времени работы
```javascript
const WORKING_HOURS = {
  start: 10,  // Начало (часы)
  end: 20     // Конец (часы)
};
```

### Изменение контактов
Найдите функцию `showContacts` и отредактируйте:
```javascript
function showContacts(chatId) {
  const text = `
📍 *Ваш барбершоп*
🏠 Адрес: ваша улица
📞 Телефон: ваш телефон
  `;
  // ...
}
```

## Безопасность

- PIN-код защищает админ-панель
- Сессия администратора истекает через 30 минут
- Ограничение на количество попыток ввода PIN (3 попытки)
- Проверка занятости слотов перед записью

## Логирование

Бот выводит в консоль:
- Статус запуска
- Ошибки polling
- Ошибки обработки сообщений

## Требования

- Node.js >= 14.0.0
- Доступ к интернету для подключения к API Telegram

## Поддержка

Если возникли проблемы:
1. Проверьте правильность токена
2. Убедитесь, что бот не запущен в другом месте
3. Проверьте права доступа к папке `data/`
4. Посмотрите логи ошибок в консоли
